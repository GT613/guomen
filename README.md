# 《过门》· 旧人成新

一款受 priest 小说《过门》人物、场景与情节启发的轻量合成叙事网页游戏。六条独立线索链分别围绕物理笔记、MP3、篮球校服、灰鹦鹉、豆豆和“姥爷”花店展开。

## 游玩

直接打开 `index.html`，或将整个文件夹上传到 GitHub 仓库并开启 GitHub Pages。

游戏会在浏览器本地自动保存进度。背景音乐使用一首轻古典钢琴曲，默认关闭，点击右上角音乐按钮后循环播放。

## GitHub Pages

1. 新建仓库，将“上传版”文件夹中的全部内容上传到仓库根目录。
2. 在仓库 Settings → Pages 中选择从分支部署。
3. 选择 `main` 分支和根目录，保存后等待生成网址。

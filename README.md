# 《过门》· 旧人成新

受 priest 小说《过门》人物、场景与情节启发的轻量合成叙事网页游戏。

## 特色

- 10 条原著主题物品链，每条 5 级，共 50 种物品。
- 50 种物品均使用独立图标，同一线索链通过统一色系和递进名称建立关联。
- 8 个章节委托，涵盖六中、物理竞赛、MP3、篮球、灰鹦鹉、豆豆、“姥爷”花店、年关细雪与重逢。
- 4 类可升级技术：线索检索、整理技法、回忆回溯、持久翻找。
- 首次进入提供四步新手引导，之后仍可通过右上角 `?` 查看玩法。
- 浏览器本地自动存档，适配手机与桌面。

## 游玩与发布

直接打开 `index.html`。上传 GitHub 时，将本文件夹内容放入仓库根目录，并在 Settings → Pages 中选择 `main` 分支根目录部署。
